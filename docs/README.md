## 1. Directory Structure

Following the official SGM Documentation Layout:

```
docs/
├── README.md                      # Central registry & sitemap (this file)
├── plan/                          # Roadmaps, PRDs, and Milestone plans
│   └── Milestone_V1.4_Plan.md     # Immediate v1.4 release plan
├── todo/                          # Living task checklists and sprints
│   └── Todo.md                    # Active task tracking
├── howto/                         # Developer setup & contribution guide
│   └── Dev_Workflow.md            # pnpm workspace, local linking, and testing
├── design/                        # Architecture & interface specifications
│   └── Architecture_SDL3.md       # SDL3 WebGL/Native hybrid design
├── progress/                      # Milestone completion reports & changelogs
│   └── V1.3_Progress.md           # Progress report for current v1.3.x line
├── reports/                       # Benchmark metrics, test logs, and rendering audits
├── issues/                        # Issue resolution records (format: DE-YYYYMMDD-<name>.md)
├── SEMVER_&_RELEASE.md            # Semantic versioning protocol and rules
├── CONTRIBUTING.md                # GitHub Flow, PR templates, and code review rules
└── lang/vi/                       # Vietnamese translations of core documents
```
