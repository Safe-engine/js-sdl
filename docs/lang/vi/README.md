## 1. Cấu Trúc Thư Mục Chuẩn SGM

```
docs/
├── README.md                      # Mục lục và sơ đồ tài liệu
├── plan/                          # Kế hoạch phát triển, PRD và lộ trình Milestone
│   └── Milestone_V1.4_Plan.md     # Kế hoạch chi tiết phiên bản v1.4.0
├── todo/                          # Danh sách công việc đang thực hiện
│   └── Todo.md                    # Bảng theo dõi Sprint & Checklist
├── howto/                         # Hướng dẫn cài đặt & quy trình lập trình
│   └── Dev_Workflow.md            # Quy trình pnpm workspace và kiểm thử
├── design/                        # Bản thiết kế kiến trúc
├── progress/                      # Báo cáo tiến độ & lịch sử thay đổi
│   └── V1.3_Progress.md           # Báo cáo tiến độ dòng phiên bản v1.3.x
├── reports/                       # Báo cáo benchmark & kiểm thử
├── issues/                        # Hồ sơ giải quyết lỗi (định dạng DE-YYYYMMDD-<tên>.md)
├── SEMVER_&_RELEASE.md            # Quy tắc đánh số phiên bản SemVer chuẩn
└── CONTRIBUTING.md                # Quy trình GitHub Flow, mở PR và Review
```
